# Sci4Fred

Sci4Fred 是 AI4Fred 的一部分，一个面向肿瘤免疫研究的 AI 科研工作台。它在你的浏览器里打开，可以读文献、整理实验记录、检查数据、写分析脚本，并把每次结果和生成它的步骤对应起来。

当前版本是第一个 macOS 测试版，先提供对话、文件阅读和结果审查。Python 和 R 分析环境会在后续更新中加入。

## 下载

打开 [最新版本](https://github.com/Frederick1607/sci4fred/releases/latest)，下载：

- `Sci4Fred-<版本号>-arm64.dmg`（Apple 芯片 Mac）

如果页面显示“没有发布版本”，说明这一版还在内部测试，请联系 Frederick 获取安装包。

## 安装

1. 双击下载好的 `.dmg` 文件。
2. 在弹出的窗口里，把 **Sci4Fred** 拖到旁边的 **应用程序** 文件夹。
3. 第一次打开前，请先看 [首次打开说明](首次打开说明.md)，按里面的步骤放行。macOS 会拦截所有没有购买苹果开发者证书的软件，这是正常现象，不是软件坏了。

安装不需要管理员权限，也不需要安装 Node、Python、R 或其他开发工具。所有需要的东西都在 Sci4Fred 里面。

## 第一次使用：填写 AI4Fred 密钥

1. 双击“应用程序”里的 **Sci4Fred**。第一次启动会多等十几秒，然后浏览器会自动打开。
2. 如果还没有密钥，页面会显示“填写 AI4Fred 密钥”。把 AI4Fred 给你的密钥粘贴进去，点“保存并检查”。
3. 检查通过后会自动进入工作台。密钥只保存在这台电脑上，页面只显示最后 4 位。

密钥不对、余额不足、网络不通时，页面会分别给出提示，不会只说“失败”。

## 以后怎么用

- **打开**：双击“应用程序”里的 Sci4Fred。已经开着的话，会直接打开浏览器，不会再启动一份。
- **退出**：在网页里点 **设置 → 常规 → 退出 Sci4Fred**。退出不会删除密钥、设置或会话。
- **换密钥**：**设置 → 常规 → AI4Fred 密钥 → 更换密钥**。保存后立即生效。

## 系统要求

- Apple 芯片的 Mac（M1、M2、M3、M4 等）
- macOS 13 或更新版本
- 约 1 GB 可用磁盘空间
- 能上网

Intel 芯片的 Mac 暂时不支持。

## 常见问题

**双击后提示“无法验证开发者”**
按 [首次打开说明](首次打开说明.md) 里的步骤，到“系统设置 → 隐私与安全性”点“仍要打开”。

**提示“已损坏，无法打开”**
通常还是 macOS 的拦截。打开“终端”，复制下面这一行，按回车，然后再双击 Sci4Fred：

```bash
xattr -dr com.apple.quarantine /Applications/Sci4Fred.app
```

**双击后没有反应，或者浏览器没有打开**
等 30 秒再试一次。如果还不行，桌面上会出现一个 `Sci4Fred诊断-…zip` 文件，请把它发给 Frederick。

**想彻底删除**
把“应用程序”里的 Sci4Fred 拖到废纸篓，再删除 `~/Library/Application Support/Sci4Fred` 文件夹。
